Lab Journal v2 is a one page lab entry template in a single offline HTML file. Top: date and experiment or project code. Per experiment: identifiers (constructs, strains, plasmids, samples), status, an optional quick table, and Result, Issue and Solution sections filled from editable template sentences with ___ blanks. Images can be cropped (nothing else) and each gets its own caption; figures are numbered automatically. Ends with Next / Tomorrow. Autosaves to the browser including images; exports Markdown, a zip with cropped PNG images, print to PDF, and draft files. v1 (the nine step wizard) is kept as a legacy release.
