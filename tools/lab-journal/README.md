Lab Journal v3 is a one page lab entry template in a single offline HTML file. Top: date and a saved experiment or project code. Per experiment: choose the experiment performed first (its filler sentences load), then what it is about, identifier tags, how it was done (protocol plus steps), changes from the normal protocol (optimization, new step, deviation, or standard protocol), status, an optional table, Result, Issue, Potential fix / follow up, and images (crop only, one caption each). Ends with Next / Tomorrow. "Save line as filler" adds any line to that experiment type's fillers for future entries. Entries, images, fillers, codes and tags are stored in the browser (IndexedDB); "Back up library" writes fillers, codes and tags to a file. Exports Markdown, a zip with cropped images, or print to PDF. v1 and v2 are kept as legacy releases.
