        Sequence Studio

        A plasmid editor that runs in this tab and nowhere else. Open your SnapGene files, see the map and the sequence, annotate, design primers, cut with enzymes, translate, and send a protein to AlphaFold 3. Nothing is uploaded anywhere.

        Opens: .dna .prot (SnapGene) · .gb .gbk .genbank .ape (GenBank) · .fasta .fa .fna .fas .seq .txt · .embl · .xdna (Serial Cloner, DNA Strider) · .json (this tool). Drop files anywhere on the page.

        Send to AlphaFold 3

        The AlphaFold Server needs a Google sign-in, so the sequence cannot be submitted from here. This downloads the job file in the server's JSON format and opens the site: there, use Upload JSON (or paste the sequence, which is also copied to your clipboard).
