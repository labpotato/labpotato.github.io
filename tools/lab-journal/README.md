Lab Journal is a single offline HTML file that walks you through one lab journal entry in nine steps: entry details, objective and success criterion, methods (with units, lots and a changes table), time stamped observations, a figure editor, results, discussion and outcome, next steps, and tags with review. It autosaves to the browser (IndexedDB, images included), exports and imports draft files, and exports Markdown with YAML front matter or a Notion zip (Markdown, PNG figures, one row notion_properties.csv). Finalizing locks the entry; afterwards only dated addenda can be added.
