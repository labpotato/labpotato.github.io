Lab Journal v4 is a day's lab report in a single offline HTML file. The date and project code sit in the top bar; experiments are columns added to the right, and any experiment can take its own date. Each experiment has coloured sections: what it is about, samples, constructs and strains (saved tags), how it was done (protocol plus numbered steps and bullets that continue on Enter), changes from normal protocol (optimization, deviation or new, each with before and this time), figures three across (crop only, one caption each), results with outcome and an optional table, issue, and potential fix / follow up. Next / Tomorrow spans the page. There are no built-in fillers: save your own, with _ marking a blank (Tab jumps to the next blank). Text boxes grow as you type, and pasting text stays text. Everything is stored offline in the browser (IndexedDB), images included, and earlier v2 and v3 entries carry over. Exports Markdown, a zip with cropped images, or print to PDF.
