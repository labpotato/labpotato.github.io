    Sequence Studio

    A plasmid editor that runs in this tab and nowhere else. Open your SnapGene files, see the map and the sequence, annotate, design primers, cut with enzymes, translate, and send a protein to AlphaFold 3. Nothing is uploaded anywhere.

    Opens: .dna .prot (SnapGene) · .gb .gbk .genbank .ape (GenBank) · .fasta .fa .fna .fas .seq .txt · .embl · .xdna (Serial Cloner, DNA Strider) · .json (this tool). Drop files anywhere on the page.

    AlphaFold 3 server

    alphafoldserver.com has no API and needs a Google sign-in, so nothing can submit for you. This is the hand-off, step by step:

    1. 1Save the job file
    2. 2Copy the sequence Copied
    3. 3Open the server, sign in, then Upload JSON (or paste into Protein)
    4. 4Drop the result .cif or .pdb on this page to view it in the panel on the left.
    
      
    
    
    
  
    
  
    
    


  
    Translated open reading frames 
    
  
    
    
    Every start codon in the stretch, drawn where it sits, at the height of its predicted translation initiation rate. A transcript carries many overlapping frames and the ribosome favours the tallest; a tall bracket you did not design is where an unexplained band comes from. The strongest frame is picked out with a dotted line from its Shine-Dalgarno to whatever terminates it.

    BLAST at NCBI 
    
  
    
    
    
      
      
      
    
      
      
    
    
    
    
    This opens NCBI BLAST in a new tab with the sequence already in the query box, then you press the BLAST button there. Opening it sends the sequence to NCBI, because their page has to receive it to show it. The search itself only runs when you press the BLAST button there.
    
  
    
      
    
    
    Bring the results back
    
    
    NCBI does not let a page read its results, so nothing can fetch them for you. Run the search there, then on the results page use Download → Hit Table (text), or just copy the description table, and paste it here.
