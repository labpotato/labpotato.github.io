Lab Journal v5 is a day's lab report in a single offline HTML file (fonts embedded: Inter and Source Serif 4, SIL Open Font License). The date and project code sit in the top bar and the page uses 80% of the screen by default. Experiments are columns added to the right. Each experiment runs: figures (upload first, three across, crop only, one caption each), what it is about, strains, plasmids and constructs (a Name and Description table), how it was done (protocol, numbered steps 1., 1.1., 1.1.1. and bullets with sub levels; Tab and Shift+Tab change the level), changes from normal protocol (before and this time), results with outcome and an optional table, issue, and potential fix / follow up. Next / Tomorrow spans the page. Names from the table are suggested while typing anywhere: a grey completion and a list appear, Tab or a click accepts. Fillers are your own, with _ marking a blank. Everything is stored offline in the browser (IndexedDB), images included, and v2 to v4 entries carry over. Exports Markdown, a zip with cropped images, or print to PDF.
