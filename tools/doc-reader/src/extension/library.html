Keeping your highlights safe

Google Drive syncNot signed in

Sign in on every computer you use, with the same Google account. Your highlights, comments and Doc Reader documents then appear on all of them. They are stored in a hidden folder in your own Google Drive that only this extension can open. In Doc Reader you can also turn on saving each document as a Google Doc.

Use your own Google Cloud project instead (optional)
  1. In Google Cloud Console, create a project and enable the Google Drive API.
  2. OAuth consent screen: External, add the scope drive.appdata, and add your own email as a test user.

Extension ID: …

A second, simpler way to share highlights between computers, through Chrome's own sync (Chrome Settings → You and Google → Sync → Extensions on). It only has room for a few hundred highlights; Google sign-in above has no such limit.

A file with all your highlights, saved once a day to Downloads/LabPotato/lab_potato_backup.json (each day replaces the last). If Chrome is reset or the extension removed, press Restore… and pick this file to get everything back.

Updating the extension: unzip the new version over the old folder and press ↻ (reload) on chrome://extensions. Your highlights stay. Pressing Remove deletes the highlights on this computer, so only do that after signing in with Google or saving a backup.
